# Cykle stałe G81–G89 — PRONUM 640FC

Ściaga i generator programów dla cykli stałych wiercenia i wytaczania sterowania **PRONUM 640FC**. PWA — działa offline na telefonie.

## Co tu jest
- **Mapa** — wybierasz zadanie (na przelot, pogłębienie, głęboki otwór, gwint, wytaczanie v1–v5) → generator
- **Generator** — cykl + parametry R (1:1 z instrukcji, rozdz. 3.15) + lista otworów + gotowe bloki do skopiowania; wariant L8x zamiast G8x
- **R-ki** — alfabet parametrów cykli stałych (R0–R11 + G80)
- **Zasady** — modalność cyklu, obowiązkowe F/S/M, G80, STOP M0 przy ręcznym wycofaniu, rezerwacje numerów L81–L89/L900–L931

## źródło
Instrukcja Programowania CNC PRONUM 640 FC (lipiec 2014), rozdział 3.15 „Cykle stałe G81 do G89".

## Instalacja jako aplikacja
Na Androidzie: Chrome → menu → „Dodaj do ekranu głównego".
